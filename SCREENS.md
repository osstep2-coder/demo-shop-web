# Экраны и состояния

Карта всех маршрутов сайта и их состояний. Нужна для съёмки видео и для скриншотных тестов.

Данные: `npm run seed` (см. [README](README.md)). Демо-аккаунты:

| Роль                | Email               | Пароль      |
| ------------------- | ------------------- | ----------- |
| Покупатель          | `anna@shop.test`    | `Qwerty123` |
| Покупатель (второй) | `ivan@shop.test`    | `Qwerty123` |
| Менеджер            | `manager@shop.test` | `Qwerty123` |
| Администратор       | `admin@shop.test`   | `admin123`  |

В интерфейсе аккаунты не подсказываются — как на настоящем сайте.

Карты для оплаты. Подходят любой будущий срок, любой CVC из 3 цифр и любое имя латиницей:

| Номер                                                                   | Результат            | Токен в API              |
| ----------------------------------------------------------------------- | -------------------- | ------------------------ |
| `4242 4242 4242 4242` (или любая другая карта, прошедшая проверку Луна) | оплата проходит      | `tok_success`            |
| `4000 0000 0000 0002`                                                   | банк отклонил платёж | `tok_declined`           |
| `4000 0000 0000 9995`                                                   | недостаточно средств | `tok_insufficient_funds` |

Номер с ошибкой (например `4242 4242 4242 4241`) не проходит проверку формы. Сопоставление номеров и токенов — в `src/lib/card.ts`.

UUID товаров фиксированные: `5a1e0000-0000-4000-8000-000000000001` … `…012` (суффикс = номер в `demo-shop-api/server/db.py`).

## Маркеры для тестов

Корневой элемент каждого состояния помечен атрибутом `data-state`. Тест ждёт нужный маркер и только потом снимает скриншот:

| `data-state` | Что это                                                                                                   |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| `loading`    | загрузка: спиннер страницы или скелетоны                                                                  |
| `empty`      | пустое состояние (нет товаров, заказов, корзина пуста)                                                    |
| `error`      | запрос к API упал: сеть, 5xx, 4xx. Внутри есть кнопка «Повторить» и строка `статус · код · correlationId` |
| `not-found`  | 404: неизвестный маршрут, товар или заказ не найден                                                       |
| `forbidden`  | 403: у роли нет доступа к разделу                                                                         |
| `crash`      | ошибка рендера (ErrorBoundary)                                                                            |

Запросы не повторяются (`retry: false`): при ошибке API экран ошибки появляется сразу. В dev-режиме `window.__queryClient` открывает кэш TanStack Query.

Как получить состояние ошибки:

- **сеть** — остановить API: dev-прокси вернёт 502, сайт покажет «Нет связи с сервером»;
- **5xx / 4xx** — замокать ответ `/api/v1/...` в тесте (Playwright `page.route`) телом `{"success":false,"error":{"code":"...","message":"..."},"meta":{"correlationId":"TEST"}}`.

## Витрина

| Маршрут          | Доступ | Состояния                                                                                                                                                                                                 |
| ---------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`              | все    | загрузка категорий и товаров (скелетоны); ошибка категорий; ошибка товаров; «всё раскупили» (`empty`, если нет товаров в наличии)                                                                         |
| `/catalog`       | все    | загрузка; список; пусто по фильтру (`?q=zzz`); ошибка; фильтры `?category=Аудио`, `?inStock=1`, `?sort=price_asc                                                                                          | price_desc | newest | name`; пагинация `?skip=9` |
| `/product/:uuid` | все    | товар в наличии; «осталось N шт.» (`…010`); нет в наличии (`…011`); скрытый товар: 404 для гостя и покупателя, бейдж «Скрыт» и «Редактировать» для сотрудника (`…012`); 404 для неизвестного uuid; ошибка |
| `/login`         | гость  | форма; неверный пароль (`auth.bad_credentials`); заблокирован (`auth.user_blocked`); вошедший пользователь перенаправляется                                                                               |
| `/register`      | гость  | форма; ошибки валидации полей; email занят (`users.email_taken`)                                                                                                                                          |

## Покупка (только покупатель)

| Маршрут             | Состояния                                                                                                                                                                                                                                                                                                                                                  |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/cart`             | загрузка; пустая корзина; товары; промокод применён; промокод не действует после изменения корзины (жёлтая плашка); ошибки промокода: `EXPIRED20` истёк, `WELCOME10` уже использован, `MINUS500` при сумме < 3 000 ₽; «до бесплатной доставки N ₽»; товара не хватает на складе (плашка, кнопка оформления выключена); модалка «Очистить корзину?»; ошибка |
| `/checkout`         | форма адреса; ошибки валидации; ошибка оформления (`orders.out_of_stock`); пустая корзина → редирект в `/cart`; ошибка загрузки                                                                                                                                                                                                                            |
| `/orders/:uuid/pay` | форма карты с превью и таймером; ошибки полей (номер, срок, CVC, имя); превью переворачивается при вводе CVC; отказ банка; недостаточно средств; время вышло; успех; заказ уже оплачен / отменён; 404; ошибка                                                                                                                                              |

## Личный кабинет

| Маршрут                 | Доступ         | Состояния                                                                                                                                                               |
| ----------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/account`              | любой вошедший | профиль; ошибка                                                                                                                                                         |
| `/account/orders`       | покупатель     | загрузка; список; фильтр по статусу `?status=…`; пусто (новый покупатель); пусто по фильтру; пагинация; ошибка                                                          |
| `/account/orders/:uuid` | покупатель     | заказ в каждом статусе (seed создаёт все шесть); таймер оплаты; модалки отмены и возврата; неудачный и возвратный платежи; 404 (чужой или несуществующий заказ); ошибка |

## Панель управления

| Маршрут               | Доступ          | Состояния                                                                                                                                                                                                                                   |
| --------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/admin`              | менеджер, админ | обзор; «заказов пока нет»; «все товары в достатке»; ошибка                                                                                                                                                                                  |
| `/admin/orders`       | менеджер, админ | таблица; фильтр по статусу; фильтр по покупателю `?userUuid=…`; пусто; быстрые «Отгрузить» / «Доставлен»; ошибка                                                                                                                            |
| `/admin/orders/:uuid` | менеджер, админ | детали с блоком покупателя (имя видит только админ); действия по статусу; 404                                                                                                                                                               |
| `/admin/products`     | менеджер, админ | таблица со скрытыми товарами; поиск; фильтр по категории; модалки создания и редактирования (`?edit=uuid`); ошибки `products.sku_taken` и валидации; пусто; ошибка                                                                          |
| `/admin/users`        | админ           | таблица; поиск, фильтры роли и статуса; карточка пользователя; блокировка и разблокировка; удаление (для покупателя с заказами — ошибка `users.has_orders`); свой аккаунт нельзя заблокировать или удалить; модалка создания; пусто; ошибка |
| `/admin/promos`       | админ           | карточки и таблица; бейджи «Действует», «Истёк», «Выключен»; модалки создания и редактирования; ошибки `promo.code_taken` и `promo.bad_value`; пусто; ошибка                                                                                |
| `/admin/*`            | менеджер, админ | 404 внутри панели                                                                                                                                                                                                                           |

## Доступ

| Ситуация                                                     | Результат                                                              |
| ------------------------------------------------------------ | ---------------------------------------------------------------------- |
| гость открывает `/cart`, `/checkout`, `/account…`, `/admin…` | редирект на `/login`, после входа — возврат на исходную страницу       |
| сотрудник открывает `/cart`, `/checkout`, `/account/orders`  | 403: «Корзина и заказы доступны только покупателям»                    |
| покупатель открывает `/admin…`                               | 403 в рамке магазина                                                   |
| менеджер открывает `/admin/users`, `/admin/promos`           | 403: «Этот раздел доступен только администратору» (пунктов нет в меню) |
| токен истёк или отозван (пользователя заблокировали)         | выход и уведомление «Сессия истекла»                                   |
| любой неизвестный маршрут                                    | 404                                                                    |
