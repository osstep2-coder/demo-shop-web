## Карты для оплаты

Подходят любой будущий срок, любой CVC из 3 цифр и любое имя латиницей.

| Номер                                                            | Результат            |
| ---------------------------------------------------------------- | -------------------- |
| `4242 4242 4242 4242` (или любая карта, прошедшая проверку Луна) | оплата проходит      |
| `4000 0000 0000 0002`                                            | банк отклонил платёж |
| `4000 0000 0000 9995`                                            | недостаточно средств |

## Промокоды

| Код         | Особенность                |
| ----------- | -------------------------- |
| `WELCOME10` | Анна уже использовала его  |
| `EXPIRED20` | срок действия истёк        |
| `MINUS500`  | действует от суммы 3 000 ₽ |
